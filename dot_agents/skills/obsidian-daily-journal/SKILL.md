# Obsidian Daily Journal Skill

## Overview
This skill helps you create, populate, and manage daily journal entries in Obsidian. It provides intelligent templating, quick capture of thoughts and tasks, and automated organization of your daily notes.

## When to Use This Skill
Use this skill when you need to:
- Create a new daily journal entry with proper formatting
- Add tasks, notes, code snippets, or blockers to today's journal
- Review or update existing daily entries
- Template out journal entries for planning ahead
- Capture quick thoughts or learnings throughout the day
